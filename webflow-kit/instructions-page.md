# Instructions page content

## Editing global styles

Open the Variables panel. Colors, typography, spacing and responsive page padding are grouped and named in Title Case. Changing a variable updates every connected section. Do not edit individual instances when a Variable or Component property exists.

## Editing sections

Header, Menu, Hero Slide, Service Card, Project Card, Client Tile, Team Hotspot, CTA and Footer are Components. Edit their main Component for global structure or use exposed properties for instance text, links, images and visibility.

## Editing projects

Open CMS → Projects. Each record controls its card and project detail page. Use Sort Order for display order, Category for filtering and Published for visibility. Keep image alt text aligned with gallery ordering.

## Editing interactions

Open the Interactions panel. Interactions use sentence-case names and native Webflow GSAP. Edit duration, delay and easing there. Loader and background video controls must remain available. Reduced-motion behavior must remain enabled.

## Replacing media

Preserve the original aspect ratio shown in the Style Guide. Compress images with Webflow's AVIF/WebP tools and keep uploads below 4 MB. Supply alt text for meaningful images and mark decorative images accordingly.

## Team hotspots

Hotspot positions are percentage based. Update each person's name and specialty through Component properties. When changing the team photograph, reposition every hotspot at desktop and all three responsive breakpoints.
