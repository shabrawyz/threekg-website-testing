# Style Guide page requirements

The native Webflow `/style-guide` page must display and label:

- all color variables and breakpoint modes
- both font families and every supplied weight
- H1 through H6
- lead, body, small and mono text
- paragraphs, text links, blockquotes, ordered and unordered lists
- buttons and links in default, hover, pressed, focus and disabled states
- form labels, inputs, textareas, select fields, validation, success and error states
- spacing ramp, page padding and grid examples
- image ratios used by hero, work cards, project gallery, clients and team
- rules, borders, overlays and inverse sections
- every Component and supported variant
- Rich Text content using the Projects class

The page is documentation only and must use the exact production variables and components so edits remain synchronized.
